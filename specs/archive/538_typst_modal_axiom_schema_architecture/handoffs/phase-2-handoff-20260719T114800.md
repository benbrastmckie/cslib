## Bugs found and fixed during incremental compile/visual review
1. Typst's built-in raw-block syntax highlighting was coloring the ```lean fenced blocks
   (blue/orange/green keywords), conflicting with the "austere, black-only body" house-style
   goal. Fixed via a two-pass `show raw.where(block: true)` rule that strips the language tag
   and forces black text (added a `maximum show rule depth exceeded` guard by branching on
   `it.lang == none`).
2. The 18-tag and diamond-duality table groups had a `rowspan` layout bug: continuation rows
   incorrectly included an extra empty `[]` placeholder cell for the spanned Role column,
   shifting Tag/Schema content out of alignment. Fixed by removing the placeholder cells (Typst's
   `table.cell(rowspan: n)` auto-skips the column for continuation rows).
3. The `Cube.lean` disambiguation table's 4th column (`auto, auto, auto, 1fr`) was squeezed to a
   near-zero width, causing vertical single-word wrapping and raw-text overflow into neighboring
   cells. Fixed with explicit fr-weighted columns and a `#text(size: 9.5pt)[...]` wrap.
- `typst compile` exit 0 after each fix; PDF visually re-inspected via `pdftoppm` after every fix.
