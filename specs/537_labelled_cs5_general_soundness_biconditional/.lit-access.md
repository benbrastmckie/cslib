## Working FTS search recipe (direct sqlite3 — the wrapper is broken):
```
sqlite3 ~/Projects/Literature/.literature.db \
  "SELECT d.doc_id, d.section_path, d.source_path
   FROM chunks_fts f JOIN chunks_data d ON f.rowid=d.id
   WHERE chunks_fts MATCH '<query>' AND d.doc_id LIKE '%simpson%'
   ORDER BY bm25(chunks_fts) LIMIT 8;"
```
Then `Read` the reported `chunks_dir/<source_path>`. Swap the `LIKE` for `%marinmorales%` for MMS.
