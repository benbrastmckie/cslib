# Typst Notation

Notation macros and shared definitions for the MPL structure-first report.

## Contents

| File | Description |
|------|-------------|
| shared-notation.typ | Shared notation conventions (copied from BimodalLogic) |
| mpl-notation.typ | MPL-specific propositional/algebraic notation macros |

## Usage

Import in Typst documents:
```typst
#import "notation/mpl-notation.typ": *
```
