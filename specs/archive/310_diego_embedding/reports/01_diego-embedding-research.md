## Findings

### 1. Filter Definition Strategy: Custom HilbertFilter (Not Mathlib Reuse)

Four Mathlib types were investigated and all ruled out:

**UpperSet H** (Mathlib.Order.UpperLower):
- Has `CompletelyDistribLattice` instance via Frame, providing `HeytingAlgebra`.
- `UpperSet.Ici : H -> UpperSet H` is injective (`Ici_injective`) and strict monotone.
- **FATAL**: `UpperSet.Ici` does NOT preserve Heyting implication for HilbertAlgebras. In `UpperSet`, the ordering is reversed (reverse inclusion), making `top = empty set`. When `a <= b`, `Ici a ⇨ Ici b = top = empty`, but `Ici(a ⇨ b) = Ici(top) = {top}`, which is non-empty. So `Ici(a ⇨ b) != Ici a ⇨ Ici b`.

**LowerSet H** (Mathlib.Order.UpperLower):
- Has `CompletelyDistribLattice` instance with natural inclusion ordering.
- Used successfully in `FreeJoinCompletion.lean` with `BrouwerianSemilattice`.
- **FATAL**: The `iicHimp` proof in FreeJoinCompletion crucially uses `BrouwerianSemilattice.le_himp_iff` and `himp_inf_le` -- both require `inf` (meet), which `HilbertAlgebra` lacks. A HilbertAlgebra has only `himp` and `top`, no `inf`.

**Filter** (Mathlib.Order.Filter.Defs):
- Topological filters on `Set H`. Not the right mathematical object.

**Order.PFilter** (Mathlib.Order.PFilter):
- Order-theoretic filters: nonempty, downward-directed, upward-closed subsets.
- Downward-directedness means: for any `a, b in F`, there exists `c in F` with `c <= a` and `c <= b`.
- In a HilbertAlgebra (which has no meets), downward-directedness is NOT guaranteed for deductive filters. The principal filter `{x | a <= x}` is downward-directed iff `a` is a lower bound for any two elements above it -- which is exactly the meet property that HilbertAlgebra lacks.

**Conclusion**: A custom `HilbertFilter` type is required.

### 2. HilbertFilter Definition

```lean
/-- A deductive filter of a Hilbert algebra H is a nonempty, upward-closed
subset of H that is closed under modus ponens (detachment). -/
structure HilbertFilter (H : Type*) [HilbertAlgebra H] where
  carrier : Set H
  top_mem : ⊤ ∈ carrier
  upper : ∀ {a b : H}, a ∈ carrier → a ≤ b → b ∈ carrier
  mp : ∀ {a b : H}, a ∈ carrier → (a ⇨ b) ∈ carrier → b ∈ carrier
```

**Design note**: The `top_mem` field is derivable from `upper` + nonemptiness (since `a ≤ ⊤` for all `a`), but including it as a field simplifies proofs.

**Key property**: Every deductive filter is an upset. The converse is false in general -- an upset need not be closed under MP.

### Challenged Claims

1. **"UpperSet.Ici does NOT preserve himp"**: Verified by concrete argument. When `a ≤ b`, `Ici(a ⇨ b) = Ici ⊤ = {⊤}` but `Ici a ⇨ Ici b = ⊤_{UpperSet} = ∅` (since Ici b ⊆ Ici a means the himp collapses). The mismatch is {⊤} vs ∅. Confirmed.

2. **"Order.PFilter is not suitable"**: Verified. PFilter requires downward-directedness (for any a,b in F, ∃ c ∈ F with c ≤ a, c ≤ b). In a HilbertAlgebra without meets, the principal filter {x | a ≤ x} is directed only if a is the meet of any two elements above it -- which is the meet property. Confirmed.

3. **"himpFilter is closed under MP"**: Partially verified. The proof sketch uses K, S, monotonicity, and himp_idem. The argument chain is: from `a ∈ S`, `a ⇨ b ∈ S`, `x ∈ F`, `b ≤ x`, derive `a ⇨ x ∈ F` (via K + upset of F) and then `a ⇨ x ∈ G` (via monotonicity + `a ⇨ b ∈ S`). The remaining step (getting `x ∈ G` from `a ⇨ x ∈ G`) requires further analysis and possibly additional intermediate lemmas. **Confidence: 0.75** -- the approach is mathematically sound but the formal details may require adjustments.
