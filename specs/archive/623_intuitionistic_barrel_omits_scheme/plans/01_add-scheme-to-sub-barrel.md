## Overview

`Cslib/Logics/Propositional/Tableau/Intuitionistic.lean` declares five of its six children and
silently skips `Scheme`, the cluster's parametric core. Research established the omission is an
oversight (git chronology), that the local sibling convention is "declare the whole chain"
(`Classical.lean`), and that the fix is provably inert for the build because the barrel already
imports `Completeness`, which itself carries `public import ...Scheme`. The work is a single
one-line addition to one file, followed by targeted verification. Definition of done: the line is
present in dependency position, the targeted module build is green, `mk_all` produces no diff, and
shake has not newly flagged the barrel.

### Research Integration

Conclusions carried forward from `reports/01_barrel-scheme-omission.md` and treated as settled --
they are **not** to be re-litigated during implementation:

- `Cslib.lean` is generated by `lake exe mk_all --module` and CI enforces exhaustiveness
  (CONTRIBUTING.md, Imports section). Its line for `Scheme` carries no intent signal and editing
  or pruning it would break CI. **`Cslib.lean` is out of scope and must not be edited.**
- Exhaustiveness is not a repo-wide convention: 13 of 26 barrels under `Cslib/Logics/` are
  partial. The decisive evidence is local, not global -- among the three tableau siblings,
  `Intuitionistic.lean` follows `Classical.lean`'s declare-the-whole-chain style and skips exactly
  one interior link.
- The true chain is `Rules -> Expansion -> Soundness -> (Minimal.Soundness) -> Scheme ->
  Completeness -> DecisionProcedure`. `Scheme` belongs strictly between `Soundness` and
  `Completeness`, matching the file's existing bottom-up (non-alphabetical) ordering.
- Transitive import closure is unchanged by the edit: zero new edges, zero cycle risk, zero
  build-cost delta. `Scheme.olean` is already a prerequisite of the barrel.
- Shake exposure assessed as near-zero (15-barrel precedent of pure re-export barrels, none
  flagged; `--keep-implied` is exactly the flag covering this shape), but the assessment was
  static and is to be **confirmed** at implementation time, not assumed.

## Rollback/Contingency

Revert the single line: `git checkout HEAD -- Cslib/Logics/Propositional/Tableau/Intuitionistic.lean`
(safe only on an otherwise-clean tree -- see the destructive-git rule; snapshot first if the tree
is dirty). Because the transitive import closure is unchanged in both directions, reverting cannot
break anything that the addition did not already leave working.

**Contingency if shake flags the file**: do not run `check-shake-residue.sh --update` to paper
over it. Stop, record the flagged path and shake's stated reason in the implementation summary,
and leave the change in place only if the targeted build and `mk_all` checks are otherwise green;
otherwise revert and escalate. A newly-flagged barrel would contradict the 15-barrel precedent and
warrants a human decision, not an automatic baseline bump.
